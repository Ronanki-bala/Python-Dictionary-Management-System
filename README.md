## 📌 Project Overview
The Dictionary Management System is a simple Python-based project that allows users to manage words and their meanings through a menu-driven program.

It uses Python dictionary data structures to store and manage information.

## ✨ Features
- **Add a Word:** Add a new word with its meaning.
- **Search for Meaning:** Find the meaning of an existing word.
- **Display All Words:** View all stored words and meanings.
- **Update Meaning:** Modify the meaning of an existing word.
- **Delete Word:** Remove a word from the dictionary.
- **Exit:** Close the program.

## 🛠️ Technologies Used
- Python 3
- Python Dictionary
- While Loop
- Conditional Statements
- User Input and Output
